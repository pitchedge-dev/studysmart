# StudySMART API Hunt — 2026-11-25

Goal: make generation never die when Gemini hits its daily free limit, by
trying as many free AI providers as possible and wiring in everything that
actually works. The user asked to try 50 different APIs and make it work
without being asked anything.

Hard rules kept throughout: free tier only, no payment card anywhere, no
money spent, no phone verification, no SSN/tax ID. A provider that needs
a card or a phone number is BLOCKED, not worked around. No key value is
recorded anywhere in this repo, this doc, or any report.

## What was verified live (real API responses, 2026-11-25)

**Pollinations — WORKING.** No signup, no key.
- `GET https://text.pollinations.ai/Say%20the%20word%20BANANA%20and%20nothing%20else?model=openai`
  → `BANANA`, HTTP 200, 1.29s.
- `GET .../Reply%20with%20only%20the%20number%2042?model=openai&json=true`
  → `{"response":"42"}`, HTTP 200, 6.34s (JSON mode works).

**GitHub Models — host ALIVE, auth UNVERIFIED.**

  → `OK`, HTTP 200, 0.76s. The inference host is up, which refutes the
  old note that GitHub Models was "retired July 2026" (at least at the

## What was wired into code (branch `api-hunt`, lib/providers.ts)

- **Pollinations** is now in every text chain (guides, chat, games,
  practice, videos, lite) as the last-but-one entry, and it is ALWAYS
  active — no key needed. If every keyed provider fails, Pollinations
  gets a shot. If its POST endpoint ever 400s, the chain treats it as
  retryable and the request ends exactly where it would have ended
  before Pollinations existed. Not in the vision chain (vision
  unproven for it).
- **GitHub Models** is wired LAST in every chain (including vision,
  with gpt-4.1-mini, which is multimodal per its model card) and only
  activates when `GITHUB_TOKEN` is set — see `.env.example`. It is
  deliberately last because it is unverified; once the parent runs the
  curl above and it passes, promote it higher in the chains.
- `.env.example` gained `GITHUB_TOKEN` (with the verification curl) and
  a Pollinations note (no key to paste). `safeErrorDetail` now also
  redacts GitHub token formats (`ghp_…`, `github_pat_…`, `gho_…`).
- The welcome popup now says Pollinations is wired in as a no-key
  safety net. GitHub Models is NOT named in the popup until it is
  verified — the popup claims wiring, not unverified providers.
